# Smart Pantry Backend Setup Guide

## What You've Built
A **FastAPI backend** with:
- Python web server (FastAPI)
- Supabase database schemas (cloud storage)

## Next Steps: Getting Started

### Step 1: Set Up Python Environment
```bash
# Navigate to backend folder
cd backend

# Create virtual environment
python -m venv venv

# Activate it
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Step 2: Create Supabase Project
1. Go to [supabase.com](https://supabase.com)
2. Click **New Project**
3. Choose a name (e.g., "smart-pantry-prod")
4. Set a strong database password
5. Choose a region (closest to your users)

### Step 3: Run Database Migrations
1. Go to your Supabase Dashboard
2. Click **SQL Editor** → **New Query**
3. Copy/paste each migration file in order:
   - `001_create_users_table.sql`
   - `002_create_recipes_table.sql`
   - `003_create_ingredients_table.sql`
   - `004_create_receipts_table.sql`
4. Click **Run** for each one

### Step 4: Enable Supabase Storage
1. In Supabase Dashboard, go to **Storage**
2. Create a new bucket: `receipt-images`
3. Make it **private** (users only see their own)
4. Add policy:
   ```sql
   CREATE POLICY "Users can upload own receipts"
   ON storage.objects FOR INSERT
   WITH CHECK (auth.uid()::text = (storage.foldername(name))[1]);
   ```

### Step 5: Get API Keys
1. Go to **Settings** → **API**
2. Copy these values:
   - **Project URL** (e.g., `https://abc123.supabase.co`)
   - **anon public** key
   - **service_role** key (keep this secret!)

### Step 6: Configure Environment
```bash
# Copy template
cp .env.example .env

# Edit .env and add your keys
nano .env
```

Fill in:
- `SUPABASE_URL`
- `SUPABASE_KEY`
- `SUPABASE_SERVICE_KEY`
- `OPENAI_API_KEY` (get from platform.openai.com)
- `STRIPE_SECRET_KEY` (get from dashboard.stripe.com)

### Step 7: Run the Server
```bash
# Start FastAPI
uvicorn app.main:app --reload

# You should see:
# INFO:     Uvicorn running on http://127.0.0.1:8000
```

### Step 8: Test It
Open your browser: `http://localhost:8000`

You should see:
```json
{
  "status": "healthy",
  "service": "Smart Pantry API",
  "version": "v1"
}
```

Visit `http://localhost:8000/docs` to see interactive API documentation (auto-generated by FastAPI).

## Troubleshooting

### "Module not found" error
```bash
# Make sure virtual environment is activated
# You should see (venv) in your terminal prompt
source venv/bin/activate
```

### "No module named 'app'"
```bash
# Run from backend/ directory, not backend/app/
cd backend
uvicorn app.main:app --reload
```

### Supabase connection fails
- Check `.env` file has correct `SUPABASE_URL` and keys
- Verify Supabase project is not paused (free tier auto-pauses after inactivity)

## Security Checklist

Before deploying to production:
- [ ] Change all default passwords
- [ ] Use strong `STRIPE_WEBHOOK_SECRET`
- [ ] Enable Supabase RLS on all tables
- [ ] Never commit `.env` file to git
- [ ] Use environment variables in production (not `.env` file)
- [ ] Enable HTTPS only
- [ ] Set up API rate limiting
- [ ] Add request logging
